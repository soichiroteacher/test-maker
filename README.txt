■ テスト問題メーカー（配布フォルダ）

 TestMaker.html   … アプリ本体。これをChromeかEdgeで開く（ダブルクリック）
 ruby-engine.js   … 自動ルビ用の辞書（約24MB）。必ず「TestMaker.htmlと同じフォルダ」に置く
                    （無くてもアプリは動くが、自動ルビは使えない）
 tools/           … 担当が変わったとき用。ruby-engine.js の作り直し手順

■ 使い始め
 1. フォルダごと、パソコンの好きな場所（またはGoogleドライブ）に置く
 2. TestMaker.html を開く → サンプルが入っています。「使い方・引き継ぎ」ボタンに説明があります
 3. 学期ごとに「バックアップ保存」（JSON）を取り、ドライブ等に置く
