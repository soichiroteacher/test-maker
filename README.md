# テスト問題メーカー

マークシート式の定期テストの**問題用紙**を作るアプリです。
本文の中で `{{語句}}` と書いた所が空欄になり、空欄の番号・選択肢の記号(ア・イ…)・語群・正答一覧を自動で整えます。
問題を入れ替えても、番号と正答は自動で付け直されます。

できあがった問題用紙は、印刷(PDF)・Word ファイルで出力できます。正答は、マークシート採点アプリにそのまま渡せます。

## 使い方

`TestMaker.html` を **Chrome または Edge** で開きます(インターネットにつながっていなくても動きます)。
使い方の説明は、画面上の「使い方・引き継ぎ」にあります。

1. 「新規」でテストを作ります。次の学期は、前のテストを「複製」して直すと早くできます。
2. 大問ごとに、本文と空欄(`{{語句}}`)、選択問題、正誤問題、記述問題を入力します。右側に問題用紙が表示されます。
3. 「印刷／PDF」または「Word出力」で問題用紙を出力します。「正答一覧」のタブで正答も確かめられます。
4. 採点するときは「採点用JSON」で正答のファイルを保存し、マークシート採点アプリの「1 正答と配点」→「テスト問題メーカーの正答を読み込む」で選びます。

### 図(画像)

- 大問の「＋ 図を追加」で、回路図や木材の図、Scratch の画面などの画像を入れられます。大問の中で**貼り付け(Ctrl+V)**や、画像をドラッグしても入ります。
- 置き場所は、大問ごとに「本文の上/本文の下/本文の右」から選びます。大きさは用紙の幅に対する割合(%)で決めます。
- 選択・正誤・記述の問題は、1問ずつにも図を入れられます(「＋ この問題に図」。その問題の欄で貼り付けても入ります)。置き場所は「問題文の下/問題文の右」です。
- 図の番号(図1・図2…)は、テスト全体の通し番号で、用紙に出る順に自動で付きます。本文で図を指すときは `〔図:見出し〕` と書くと、その図の番号に置き換わります(大問を並べ替えても番号が合います)。
- 白黒で印刷するので、色の付いた図は「白黒にする」で見え方を確かめてください。
- 図は、印刷/PDF にも Word 出力にも入ります。Word では、図は文の中に置かれた絵として入るので、Word で大きさを変えることもできます。

### コードの欄(プログラムの問題)

- 大問の「＋ コードの欄を追加」で、プログラムを書く欄が出ます。字下げは書いたとおりに、字の幅がそろった字体(BIZ UDゴシック)で、枠に囲んで出ます。行番号も付けられます。
- 語群選択の大問では、コードの中も `{{答え}}` で空欄にできます。番号・語群・正答は、本文の空欄と同じく自動で付きます。
- 見本のテストの大問7に、例があります。

### 漢字のルビ(読みがな)

- `[漢字|かんじ]` と書くと、その漢字にルビが付きます。
- 「漢字すべてに自動でルビ」をオンにすると、自動で読みが付きます。これには、同じフォルダに `ruby-engine.js`(自動ルビ用の辞書、約24MB)が必要です。無くても、ほかの機能は使えます。
- 自動の読みはまちがうことがあります。出力の前に「ルビの確認・辞書」で確かめ、直した読みは辞書に登録してください。

## データの保存場所

- 作った問題は、**データファイル `テスト問題メーカー_データ.json`** に自動で保存されます(直すたびに上書きされます)。
- データファイルは、**`TestMaker.html` と同じフォルダ**(校務共有サーバーのフォルダ)に置いてください。そうすると、別のパソコン・別のブラウザで開いても、同じデータを使えます。
- はじめて開いたときに、次のどちらかを選びます。
  - **データファイルを新しく作る**:はじめて使うとき。保存する場所に `TestMaker.html` と同じフォルダを選びます。
  - **データファイルを開く**:同じフォルダに `テスト問題メーカー_データ.json` がすでにあるとき。
- 開き直したとき、ブラウザが「このファイルの編集を許可しますか?」のようにたずねることがあります。**「ファイルを編集」(または「許可」)** を押してください。
- 画面上の帯が**黄色や赤**のときは、データファイルに保存できていません。帯のボタンを押してください。
- 控えとして、ブラウザの中(パソコンごと・ブラウザごとに別)にも保存しています。
- 図の画像も、データファイルとバックアップに入ります。図が多いとファイルが大きくなります(大きな画像は、読み込むときに自動で小さくします)。
- 同じデータファイルを、2つの画面やパソコンで同時に直さないでください。別の所で変更されたときは、上書きせずに止めてお知らせします。
- 問題には個人情報が入らないので、成績のデータとは別に扱えます。

## バックアップと復元

- **バックアップ**:画面上の「バックアップ保存」を押すと、`テスト問題メーカー_バックアップ_日時.json` がダウンロードされます。全部のテストと、登録したルビの辞書が入ります。学期ごとや、大きく直したあとに保存し、校務共有サーバーに置いてください。
- **復元**:「読み込み」で、保存したバックアップのファイルを選びます。今のテストは消えず、新しいテストとして加わります。
- データファイルも、バックアップと同じ形です。「読み込み」で開くこともできます。
- 画面上には、最後にバックアップした日時と「未バックアップの変更あり」が表示されます。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 前に作ったテストが見えない | 画面上の帯の「データファイルを開く」(または「保存先を変える」→「データファイルを開く」)で、`テスト問題メーカー_データ.json` を選んでください。データファイルを使う前に作ったテストは、前のブラウザで開くと控えに残っています。 |
| 「別の画面か別のパソコンで変更されました」と出る | ほかの所で同じデータファイルが直されました。ふつうは「ファイルを読み直す」を押します。この画面で直した分も残したいときは、聞かれたときに「OK」を押すと、別のテストとして加わります。 |
| 「保存できませんでした」と出る | 共有サーバーにつながっているか確かめて、「もう一度保存」を押してください。 |
| まちがって消した・壊した | 「履歴」から、前の状態を新しいテストとして復元できます。 |
| 「図…の画像が見つかりません」と出る | 図の入っていない古いバックアップから読み込んだ可能性があります。その図を入れ直してください。 |
| 「〔図:…〕の図がありません」と出る | 〔図:〕の中の言葉を、図の見出しと同じにしてください。 |
| 自動のルビが付かない | `ruby-engine.js` が `TestMaker.html` と同じフォルダにあるか確かめてください。 |
| 番号や記号の警告が出る | 警告の文に、どの大問のどこを直せばよいかが書いてあります。 |
